What gets sent
Your own workflows

Start from ours: download the workflow this model renders with, open it in ComfyUI, change only what you need — a different sampler, a LoRA, an upscale — and upload it back. Keep it simple: extra branches and custom nodes are what makes an upload fail to map.

In ComfyUI, use Workflow → Export (API) and upload that file. It needs one KSampler, a text node on its positive and negative, an Empty Latent for the size, and a Save Image. The normal save of the same workflow is optional: it lets the PNG reopen in ComfyUI. Workflows are private to you; the owner approves each one before it can run.

Render models

Only files listed here appear in a model's Model dropdown. A file's settings load when someone picks it; blank fields fall back to the model's preset. The prefix goes in front of every prompt rendered with that file; the negative replaces the model's basic one.

Workflows waiting for you

Uploaded by people you let render. A workflow is a program ComfyUI runs on this box: check the node types are ones you know before approving. Refuse deletes it.

LoRAs

Matched to models by what each file says it was trained on. Tick models to override that; trigger words join the prompt whenever the LoRA is switched on.

Model usage

Every time a model is asked for something, it counts one — prompt writing, second passes, chat and reference analysis. A model sitting on 0 runs is one nobody has picked since counting started. Only the models this box is serving are listed; counts under any other name are behind the button at the bottom.

How chat works
Where it lives
On this machine, under your account. Conversations never leave the box, and no one else can open yours — not even the owner.
What deletes them
Nothing automatic.
Keeping one
Click the padlock on a conversation. A locked one is never auto-deleted, however old it gets. You can still delete it yourself — it will ask first.
There is no undo
Deleting is permanent and there is no backup. The same goes for removing an account: it takes that person's conversations and saved prompts with it.
It shares the GPU
Chat and prompt generation use the same model and the same queue, so a long generation can hold your answer up for a moment. The active users panel on the right shows who has it.
The model reads the whole conversation
Every turn sends the full history back, which is what makes it a conversation. Start a new chat when you change subject and the answers get sharper.
Web search is a button
Press Search beside the message box and that message is searched for before it is answered, with the results handed to the model and cited inline as numbered links you can click. It stays on until you turn it off. Without it, answers come from training data alone — for anything recent or version-specific, assume it is guessing and check.
Where the queries go
Your search terms leave the machine when you use it. Everything else about a conversation stays here.
