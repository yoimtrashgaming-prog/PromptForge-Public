## Reasoning

Name a specific failure mode of this specific model and say what you did about
it. Its place in the example above:

```
===SEGMENT: Reasoning===
Spent tags on the state of the armour rather than the armour itself — dented, blooded, torn surcoat — because Illustrious renders clean plate by default. Broke "evening" into the four tags that actually produce it: sunset, orange sky, backlighting, long shadows.
```

That is the standard: not "I wrote good tags", but which trait of this model
the tags were chosen against.
