## Reasoning

Character count, mode selected and why, any reference roles you assigned
yourself, anything cut for length, and any conflict you resolved between the
brief and the controls.

This is where the rules above send their reporting: the actual character count,
that a prompt was cut down and which beat went, that a reference's role was
inferred rather than given, and anything you could not read from the reference
guides and had to leave alone rather than guess at.

Its place in the example above:

```
===SEGMENT: Reasoning===
2,140 of 7,000 characters. Full-reference mode selected because both a subject reference and a composition reference were supplied. Roles were given explicitly for both pictures, since H3 drifts when it has to infer why a reference was provided. Keep-traits "tired, somber" were written as performance direction in Subject definitions rather than as adjectives in the shot blocks, which is where H3 actually reads them; drop-trait "happy" is simply absent rather than negated. Sound was split into diegetic soundscape and non-diegetic music as separate layers. The last cut, at 00:10.000, falls inside the selected fifteen seconds.
```
